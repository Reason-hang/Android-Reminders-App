# ReminderApp v0 品牌规范

## 1. 定位

ReminderApp 是个人提醒工作台，不是内容展示型 App。设计优先级为：

1. 快速扫描和识别提醒。
2. 快速完成、延后、整理和恢复。
3. 用暖琥珀色建立品牌记忆点。
4. 用动效解释状态变化，但不干扰提醒可靠性。

本规范对应 `design/v0/index.html`，是后续 Android Compose 视觉实现的 v0 基线，不改变数据库、路由、提醒调度、通知权限和诊断协议。

## 3. 颜色系统

| Token | 色值 | 用途 |
|---|---|---|
| `primary` | `#FDB833` | 保存、确认、选中、主操作 |
| `onPrimary` | `#201B13` | 主色按钮上的文字和图标 |
| `primaryContainer` | `#FFF0C8` | 选中卡片、提示区、轻强调 |
| `background` | `#F4F0E8` | 原型工作台背景 |
| `surface` | `#FFFCF7` | Android 页面背景、卡片、表单 |
| `surfaceRaised` | `#FFFFFF` | 输入框、设置项、诊断卡片 |
| `onSurface` | `#201B13` | 标题、正文 |
| `onSurfaceVariant` | `#6F6658` | 辅助文字、说明文字 |
| `outline` | `#E8DFCE` | 边界、分割线、输入框 |
| `brandDeep` | `#8A5D00` | 琥珀色上的深色文字、时间、状态 |
| `success` | `#297755` | 已开启、已确认、完成 |
| `error` | `#B3261E` | 删除、异常、永久删除 |

### 使用规则

- `#FDB833` 只承担品牌和操作语义，不作为白底小字号正文。
- 主色按钮使用深色文字，不能使用白色文字覆盖琥珀色。
- 删除使用红色，成功使用绿色，不能让品牌色覆盖语义色。
- 同一界面主要颜色不超过 4 种：背景、表面、正文、主色。
- 所有主色文字必须改用 `brandDeep` 或 `onPrimary`，避免低对比度。

## 4. 字体和排版

使用 Android 系统中文字体，保持跨设备稳定；不引入额外字体依赖。

| 层级 | 建议尺寸 | 字重 | 用途 |
|---|---:|---:|---|
| 页面标题 | 26–28sp | 700–800 | 首页、编辑页、设置页标题 |
| 强提醒标题 | 30–32sp | 800 | 强提醒主标题 |
| 区块标题 | 12–14sp | 700 | 未完成、设置分组 |
| 正文 | 13–16sp | 400–600 | 提醒标题、说明 |
| 辅助信息 | 10–12sp | 400–700 | 时间、分类、状态 |
| 操作标签 | 11–12sp | 700–800 | 置顶、置底、恢复 |

原则：先保证标题和时间可扫读，再压缩辅助信息；长标题最多显示 4 行，超过显示省略号。

## 5. 间距、圆角和阴影

- 基础间距：4dp；常用倍数：8、12、16、20、24dp。
- 页面左右内边距：16–20dp。
- 首页列表行间距：4–6dp。
- 短提醒列表行目标高度：58–64dp；日期、时间、重复规则统一放在标题下方，时间不再单独占左侧列。
- 小控件圆角：10–12dp。
- 卡片和设置项圆角：12–16dp。
- 页面和强提醒容器圆角：24–28dp。
- 只使用两级阴影：普通卡片轻阴影，主要操作和设备框深阴影。
- 不给每一块文字都包卡片；卡片只用于分组、选择、操作和状态承载。

## 6. 图标规范

- 采用线性图标，默认 18–20dp。
- 撤销：左弯箭头。
- 重做：右弯箭头。
- 保存：对勾。
- 整理：列表线条。
- 已删除：回收站。
- 置顶/置底：上下箭头。
- 每个图标按钮必须具备 `contentDescription`。
- 对不熟悉的图标提供长按提示；保存和删除尤其不能只依赖图标形状。
- 不使用 emoji 代替功能图标。

## 7. 动效规范

### 时间 token

| Token | 时长 | 适用场景 |
|---|---:|---|
| `fast` | 150ms | 按钮按下、复选框、颜色变化 |
| `standard` | 210ms | 列表位移、页面淡入、状态切换 |
| `emphasis` | 300ms | 整理模式、底部操作栏、重要反馈 |

### 动效映射

- 新增、完成、删除：淡入、滑出、列表重新排布。
- 整理模式：顶部栏和底部操作栏滑入/滑出。
- 多选：复选框轻微弹性缩放，卡片转为浅琥珀背景。
- 拖拽排序：卡片抬升、阴影增强、其他卡片让位。
- 保存：对勾出现短暂完成反馈。
- 错误：单次轻微左右抖动，不循环。
- 强提醒：只做一次进入动效，不持续闪烁、不装饰性循环。

### 无障碍

- 遵守系统 `prefers-reduced-motion` / Android 动画缩放设置。
- 降低动效时保留状态变化、内容顺序和操作结果。
- 不能把“动画结束”作为业务成功的唯一判断。

## 8. 页面应用规则

| 页面 | 核心任务 | 视觉重点 |
|---|---|---|
| 首页 | 扫描和进入提醒 | 高密度列表、时间优先、浅琥珀筛选 |
| 整理模式 | 多选和排序 | 选中态、置顶/置底/删除底栏 |
| 新建/编辑 | 快速录入和保存 | 时间、提前、重复连续排列；图标操作 |
| 已删除 | 恢复误删事项 | 多选、恢复、永久删除 |
| 设置 | 查看和修复权限 | 状态优先、解释折叠 |
| 诊断 | 识别链路断点 | 证据摘要、时间线、状态标签 |
| 强提醒 | 立即理解并处理 | 高对比、单一主标题、明确操作 |

编辑页的提醒时间使用左右双栏：左侧为日期选择器，右侧为时间滑动选择器；两者视觉上属于同一个提醒时间字段。

首页日期显示规则：相对基准日当天显示“今天”，次日显示“明天”，后日显示“后天”；第 4 天及以后显示 `MM月DD日`。跨年日期显示完整年份。首页排序提供“手动优先级”“按提醒时间”“按创建时间”三种方式，默认保持按提醒时间，成功完成置顶/置底/拖拽后切换为手动优先级。

## 9. 受保护的产品契约

本 v0 只改视觉表达，不改变：

- 提醒数据字段、数据库迁移和 Room 映射。
- AlarmManager、Receiver、Foreground Service 和强提醒身份校验。
- 通知、全屏提醒、悬浮窗、精确闹钟等权限行为。
- 回收站软删除、恢复、永久删除和调度取消/恢复规则。
- 标题 500 字限制、首页 4 行省略规则。
- Reminder Black Box 的事件字段和诊断导出协议。
