## 维护规则

- 长文档使用章节编号和普通 Markdown 目录；短文档只保留必要目录。
- 仓库内部链接统一使用相对路径，不依赖 `[TOC]`、编辑器插件或本机绝对路径。
- 稳定文档不在文件名中写日期或“最终版”；历史过程由 Git 追溯。
- 版本、功能、目录或验证状态变化时，同步更新 README、PRD、交接、总索引和受影响报告。
- 未实际执行的测试必须写“待验证”，不得复制旧版本数字或把自动化结果当作真机通过。
