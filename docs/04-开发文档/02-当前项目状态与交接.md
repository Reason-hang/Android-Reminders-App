## 架构不变量

- `ADVANCE`、`DUE`、`SNOOZE` 独立；只有 `DUE` 推进重复周期。
- 事件、操作和超时按 `reminderId + alarmId + kind + occurrenceTime` 隔离。
- 回收站数据绝不参与 `getAllPending()` 或 AlarmManager 重建；永久删除只允许针对 `DELETED`。
- 手动排序只影响首页未完成事项的展示顺序，不改变领域时间字段和系统闹钟。
- Room 与 AlarmManager 没有跨系统事务；新增、恢复等操作采用补偿逻辑，失败必须保留可解释状态。
- 不引入网络、音频采集、语音模型、账号或云备份。
