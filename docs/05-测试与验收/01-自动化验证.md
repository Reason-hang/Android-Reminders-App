## 实际命令

```bash
JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home \
ANDROID_HOME=/opt/homebrew/share/android-commandlinetools \
./gradlew testDebugUnitTest :app:compileDebugAndroidTestKotlin \
  --rerun-tasks --console=plain --warning-mode=none
```

```bash
JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home \
ANDROID_HOME=/opt/homebrew/share/android-commandlinetools \
./gradlew lintDebug assembleRelease \
  --rerun-tasks --console=plain --warning-mode=none
```

v1.10 以 JDK 17 实际执行：`testDebugUnitTest`、`compileDebugAndroidTestKotlin`、单线程 `lintDebug` 与单线程 `assembleRelease` 均退出码 0。JVM 数量从 XML 汇总为 93；Lint 为 0 error、63 warnings、3 hints。随后用 ADB `install -r` 覆盖安装，设备侧确认 `versionName=1.10`、`versionCode=11`。

首次将 Lint 与 Release 放在同一并行 Gradle 调用中时，Android Lint 读取了被 Release 重建的 KAPT 临时 stub，出现 Lint 内部异常；拆分为串行单线程任务后恢复通过。这是构建竞态，不是本次源代码规则错误。
