## 实际命令

```bash
JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home \
./gradlew testDebugUnitTest :app:compileDebugAndroidTestKotlin \
  --rerun-tasks --no-daemon --console=plain \
  -Dkotlin.compiler.execution.strategy=in-process -Dkotlin.incremental=false

./gradlew lintDebug --no-daemon --console=plain \
  -Dkotlin.compiler.execution.strategy=in-process -Dkotlin.incremental=false

./gradlew assembleRelease --no-daemon --console=plain \
  -Dkotlin.compiler.execution.strategy=in-process -Dkotlin.incremental=false
```

本机 Kotlin 增量缓存曾出现文件锁冲突，已停止残留 daemon 后使用进程内、非增量编译取得通过结果；这是构建环境问题，不是源码规则错误。Lint 与 Release 按串行单任务执行，避免并发读取 KAPT 临时产物。
