## 安全结论

应用是离线单机工具，未发现远程执行、远程数据传输或账号访问控制链路。APK 未声明 `INTERNET`，不包含 WebView、动态代码执行、外部文件导入、登录、云同步或统计 SDK。

## 已验证控制

- 业务 Activity、Receiver 和 Service 默认不导出；Launcher 仅用于打开应用。
- 自动关闭广播使用运行时非导出 Receiver，并显式限制为本应用包。
- PendingIntent 使用 immutable 标志；未发现 `FLAG_MUTABLE`。
- Room 禁止破坏性迁移，应用备份和设备迁移关闭。
- 未发现 API key、token、密码、私钥、带凭据连接串或自定义加密实现。
- 日志不记录提醒标题和备注正文。
- `.gitignore` 排除构建产物、APK、签名文件、本机配置和常见密钥文件。

## 权限用途

| 权限 | 用途 |
|---|---|
| `USE_EXACT_ALARM` / `SCHEDULE_EXACT_ALARM` | 精确调度提醒 |
| `POST_NOTIFICATIONS` | Android 13+ 发布通知 |
| `USE_FULL_SCREEN_INTENT` | 锁屏强提醒入口 |
| `RECEIVE_BOOT_COMPLETED` | 重启后恢复未来闹钟 |
| `VIBRATE` / `WAKE_LOCK` | 震动和短时唤醒屏幕 |
| `FOREGROUND_SERVICE_MEDIA_PLAYBACK` | 到点持续响铃和振动 |

不申请 `INTERNET`、存储、通讯录、定位、相机、麦克风或设备管理权限。

## 残余风险

| 级别 | 风险 | 当前处置 |
|---|---|---|
| Medium | Release 使用 Android Debug 签名 | 仅用于个人直装和测试；正式发布前切换用户保管的 keystore |
| Low | 锁屏公开展示标题和备注 | 产品要求；用户不应填写密码、验证码等敏感内容 |
| Info | 依赖 CVE 未联网重新核验 | 不宣称依赖零漏洞；后续联网审计单独执行 |
| Info | Lint 保留 59 warnings、3 hints | 当前无 error；按风险维护，不等同于安全漏洞 |
| Info | HyperOS 权限和通知渠道状态未读取 | 目标手机未连接，按真机清单补验 |

安全结论不覆盖目标设备 root、ADB 手工篡改数据库、恶意定制 ROM 或用户主动授予第三方设备管理权限的场景。
