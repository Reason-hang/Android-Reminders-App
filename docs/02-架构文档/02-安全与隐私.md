## 安全结论

应用是离线单机工具，未发现远程执行、远程数据传输或账号访问控制链路。APK 未声明 `INTERNET`，不包含 WebView、动态代码执行、外部文件导入、登录、云同步或统计 SDK。

## 已验证控制

- 业务 Activity、Receiver 和 Service 默认不导出；Launcher 仅用于打开应用。
- 自动关闭广播使用运行时非导出 Receiver，并显式限制为本应用包。
- PendingIntent 使用 immutable 标志；未发现 `FLAG_MUTABLE`。
- Room 禁止破坏性迁移，应用备份和设备迁移关闭。
- 回收站只保存既有本地提醒字段；永久删除要求二次确认，且不提供绕过回收站的 UI 入口。
- 未发现 API key、token、密码、私钥、带凭据连接串或自定义加密实现。
- 日志不记录提醒标题和备注正文。
- 诊断事件、增强快照和 ZIP 均保存在应用私有目录；只在用户主动点击导出时经临时 `FileProvider` 授权分享，不申请存储权限、不联网。
- `.gitignore` 排除构建产物、APK、签名文件、本机配置和常见密钥文件。
- 撤销/重做历史只存在编辑页 ViewModel 内存中，保存、离开页面或进程结束后丢弃，不新增持久化敏感数据。

## 权限用途

| 权限 | 用途 |
|---|---|
| `USE_EXACT_ALARM` / `SCHEDULE_EXACT_ALARM` | 精确调度提醒 |
| `POST_NOTIFICATIONS` | Android 13+ 发布通知 |
| `USE_FULL_SCREEN_INTENT` | 锁屏强提醒入口 |
| `SYSTEM_ALERT_WINDOW` | 用户显式授权后，在设备已解锁时显示应用悬浮强提醒页 |
| `RECEIVE_BOOT_COMPLETED` | 重启后恢复未来闹钟 |
| `VIBRATE` / `WAKE_LOCK` | 震动；`WAKE_LOCK` 保留给系统兼容能力，强提醒不在通知前主动点亮屏幕 |
| `FOREGROUND_SERVICE_MEDIA_PLAYBACK` | 到点持续响铃和振动 |

不申请 `INTERNET`、存储、通讯录、定位、相机、麦克风或设备管理权限；不实现录音、音轨、语音转写或语音备份。

`SYSTEM_ALERT_WINDOW` 是高影响特殊权限，约束如下：仅在 Receiver 已触发、前台提醒服务已启动且设备处于解锁交互态时创建窗口；窗口内容只来自当前本地提醒；关闭、完成、稍后、实例接管、十分钟超时或 Service 销毁时立即移除；权限未开启时不尝试绕过，退化为系统通知并在诊断中记录失败。应用不得在无提醒会话时显示悬浮内容。

## 残余风险

| 级别 | 风险 | 当前处置 |
|---|---|---|
| Medium | Release 使用 Android Debug 签名 | 仅用于个人直装和测试；正式发布前切换用户保管的 keystore |
| Low | 锁屏公开展示标题和备注 | 产品要求；用户不应填写密码、验证码等敏感内容 |
| Info | 依赖 CVE 未联网重新核验 | 不宣称依赖零漏洞；后续联网审计单独执行 |
| Medium | 悬浮层可覆盖其他应用，误用会造成打扰或钓鱼风险 | 必须用户显式授权；只在真实强提醒会话显示，界面固定、可关闭、十分钟自动移除，不提供任意内容入口 |
| Info | Lint 保留 67 warnings、4 hints | 当前无 error；按风险维护，不等同于安全漏洞 |
| Info | 悬浮权限由用户或系统撤销后，解锁强提醒会降级为系统横幅 | 首页和设置页提示权限状态；诊断记录 `overlay_failed=permission_missing`，媒体链路不受影响 |

安全结论不覆盖目标设备 root、ADB 手工篡改数据库、恶意定制 ROM 或用户主动授予第三方设备管理权限的场景。
